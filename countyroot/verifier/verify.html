Verify a parcel

Checks one parcel against the county's fingerprint on Solana, in your browser.

Not a deed. Not a title. Not a token. A match means this parcel row is in the county extract CountyRoot fingerprinted. The county remains the legal source.

How this works

  1. Your browser downloads a few small proof files for this county (about 100 KB or less each), not the whole parcel list.
  2. If the exact ID isn't in the county file, it tries the same ID without case, spaces, dashes, dots or leading zeros, then any lookup aliases the county has (for example Travis's TCAD Property ID). It always tells you which parcel ID it matched. Aliases only help find the parcel ID; they are not part of the fingerprint.
  3. It recomputes the parcel's fingerprint (leaf) from the row: sha256(parcel_id|acres|lot_sqft).
  4. It hashes that leaf up the Merkle tree to a root, using the neighbouring fingerprints from the proof files.
  5. It reads the county's root account from Solana Devnet (finalized) and checks it is CountyRoot's, active, for this county and epoch, and equal to the computed root.

The proof files are not trusted: if any byte in them is wrong, the computed root won't match. If Solana can't be reached, the page compares with the fingerprint published on this site instead and tells you so; open the Explorer link to confirm it yourself. For a check that doesn't rely on this website, use the CountyRoot SDK's countyroot verify with the full parcel list.
